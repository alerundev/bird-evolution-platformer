# 날개를 찾아서 — 바람섬 대모험

외부 라이브러리나 이미지 파일 없이 브라우저에서 바로 실행되는 단일 HTML 횡스크롤 플랫폼 게임입니다.

## 실행

`index.html`을 브라우저에서 열거나, 저장소를 정적 SPA 웹 호스팅에 배포하세요. 빌드 단계가 필요하지 않습니다.

## 조작

- 좌우 이동: `←` / `→` 또는 `A` / `D`
- 점프: `Space`, `↑` 또는 `W`
- 공룡 레이저 공격: `F`
- 재시작: `R`
- 모바일: 화면 아래 이동·점프·불꽃 터치 버튼

물고기를 모으면 병아리(2마리), 갈매기(4마리), 공룡(7마리)으로 진화합니다. 공룡이 된 후 돼지 대장에게 불꽃을 세 번 맞히면 승리합니다.
